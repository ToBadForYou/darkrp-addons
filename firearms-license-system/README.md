# Firearms license system for DarkRP
A firearms license system modification for Garry's Mod written in 2017, the code is very old and outdated but should still be functional. Feel free to use and modify the code as you wish but remember to give credit. 

It used to be sold on gmodstore and you can view more details [here](https://www.gmodstore.com/market/view/a699a8e0-b9dd-479a-8a28-d442dd452e16)

Requires version 2.5.0+ version of DarkRP and CSS content to be installed
